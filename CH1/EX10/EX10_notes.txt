Exercise 10
===========

I cloned the public ACP-Examples repository and examined the monolithic
Legendre plotting program in CH1/LEGENDRE/MONOLITH. The repository was on
the master branch with a clean working tree.

The original program did not compile with Apple Clang because the Apple
C++ standard library does not provide std::legendre.

Command:

    clang++ -std=c++20 -Wall -Wextra -pedantic legendre.cpp -o legendre

Output:

    legendre.cpp:57:21: error: no member named 'legendre' in namespace 'std'
       57 |     double y = std::legendre(l, x);
          |                     ^~~~~~~~
    1 error generated.

I copied the program into my EX10 directory instead of changing the
author's repository. I replaced std::legendre with a local implementation
of the Legendre recurrence relation. The compatible program successfully
plotted P_4(x) as an ASCII graph.

For the new special function, I chose the physicists' Hermite polynomials.
They have a recurrence structure similar to the Legendre polynomials:

    H_0(x) = 1
    H_1(x) = 2x
    H_(n+1)(x) = 2x H_n(x) - 2n H_(n-1)(x)

I plotted orders 0 through 4 on the interval [-2, 2]. The vertical scale
was calculated separately for each order because Hermite polynomials are
not restricted to the range [-1, 1].

Command:

    for n in 0 1 2 3 4; do
        ./hermite "$n" > "hermite_${n}.txt"
    done

Command:

    ls -l hermite_*.txt

Output:
